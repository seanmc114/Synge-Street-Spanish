# Synge Street Spanish

Opinion pieces (LC Higher, Section B Q5) and blog posts (Junior Cycle), marked by Markus to the SEC schemes.
A Loops Learning Tool.

| File | What it is |
|---|---|
| `index.html` | The whole app. Titles are in `LC_TITLES` and `JC_BLOGS` near the top of the script: add or delete lines freely. |
| `manifest.webmanifest`, `assets/` | Home-screen icon (Loops triskel) and favicons. |

Markus lives in the Loops Test Centre Worker (`WORKER_URL` in `index.html`). Nothing to set up in Cloudflare for this repo.
If the Worker's `ALLOWED_ORIGINS` setting is filled in, add this site's address to it.

Settings at the top of the script: `TEST_CENTRE_URL` (footer link), `PASS_BUY_URL`, `SLIPS_FIRST`, `ALLOW_PASTE`.
